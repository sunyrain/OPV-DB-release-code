Literature sources and supplementary database searches

The collection combines an in-house literature library with supplementary Web of Science and Scopus searches and publisher article materials. The in-house library supplied the publications before 2020. Sources with reliable publication years span 2011–2026. The Li dataset was used as a reference for material names and annotations.

The accompanying query table records the available supplementary search definitions. Actual request logs include January, March and April 2026. Web of Science queries use TS syntax; Scopus queries use TITLE-ABS-KEY syntax. Broad photovoltaic terms are combined with alternative material, performance and processing terms. Names such as Y6, PM6 and ITIC are optional alternatives, rather than mandatory terms for every article.

The device-table DOI lists identify the included sources. Metadata from the supplementary searches were linked to the in-house collection and deduplicated by DOI before extraction.
